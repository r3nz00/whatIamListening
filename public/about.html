Sobre mí y el proyecto

¡Hola! Soy Renzo, un estudiante y desarrollador radicado en Montevideo, Uruguay. Me apasiona crear herramientas útiles, experimentar con código (especialmente en entornos Linux) y, por supuesto, escuchar buena música durante todo el proceso.

whatIamListening nació como un proyecto personal para unir el desarrollo web con mi día a día. Quería una forma limpia y directa de compartir en tiempo real los temas que escucho y permitir que otras personas interactúen recomendándome sus canciones favoritas.

Técnicamente, el widget está construido desde cero bajo una arquitectura MVC utilizando PHP, Vanilla JavaScript y una integración directa con la API oficial de Spotify para obtener los metadatos en milisegundos.

Si te interesa explorar el código fuente de este proyecto, revisar otras de mis herramientas de software o simplemente conectar, puedes darte una vuelta por mi repositorio.
